# Player module

- `player_page.dart`: playback session route and native-player lifecycle.
- `workflow/`: source discovery, resolution, and opening playback.
- `models/`: playback values shared by the player session and UI.
- `state/`: cached sources and persisted source/subtitle preferences.
- `mappers/`: protocol stream to native-player mapping.
- `controls/`: transport controls, timeline, buffering, and live-edge behavior.
- `sheets/`: source, quality, and subtitle selection surfaces.
- `widgets/`: reusable player-facing widgets and native player view.
- `diagnostics/`: player event and error diagnostics.
